# Asset provenance

## Basalt base color

`Textures/Basalt_Albedo.png` was created with the built-in image generation tool under the imagegen skill and copied into this project. Original generated file: `C:/Users/LENOVO/.codex/generated_images/01a18fec-d19f-7953-834e-9891f1f3960b/exec-4ccf818f-1095-4a0a-b90f-b11273911e9b.png`.

Prompt used:

> Use case photorealistic-natural. Asset type: seamless square 2048x2048 game texture, volcanic basalt rock base color/albedo. Orthographic perfectly top down, full frame filled with charcoal grey cooled basalt lava pavement, intricate ropey pahoehoe folds and fractured broad rock plates, natural microporous pitted stone grain, subtle brown grey ash dust, medium dark but readable mineral detail, no emissive lava, no orange/red glow, no objects, no perspective, no horizon, no text, no borders. Neutral diffuse flat lighting, no baked cast shadows or specular highlights. Organic multiscale cracks not regular polygons. Seamless repeat on both axes, evenly distributed features and no central focus. Realistic high fidelity rock surface intended for a Unity battlefield floor and cliffs.

The prompt requested a seamless albedo; the result is AI imagery with some baked surface shading. It is not a measured PBR scan. Shader relief is inferred from brightness and is an artistic approximation.

## Authored resources

- All Volcano meshes: generated by `Scripts/Editor/VolcanoBuilder.cs`, fixed seed 83417 by default.
- Basalt, lava, sky and heat-haze shader code: authored locally for the existing URP project.
- `Textures/SmokeDensity.asset`: radial/noise density generated in the builder, not a downloaded image.
- `Audio/VolcanicRumble.wav`: authored locally from filtered seeded noise and low-frequency sine components, 12 seconds / 22050 Hz / mono PCM16. No audio extracted from the reference video.
- Particle systems, lights, geometry and materials: authored in the Volcano scene/prefab.

## Existing game resources

Gundam/enemy rigs, animations, battle effects, UI and game logic are reused from the user's existing TurnBasedBattle project. No ownership claim is made over source robot/game assets.
