- Shipping Container Environment / Free Shipping Containers: existing project package, readme author MutantGopher. Uses container variants/open variants, warehouse, slabs, rails and ladder. Material copies live under SunkenHarbor.
- Industrial Tanks: existing Round_tanks.fbx and Long_Tanks.fbx, including supplied materials/textures.
- Photoscanned MoutainsRocks PBR by TheTalesFactory: existing project rock prefabs and their albedo/normal sources. Material copies use marine-growth shading.
- Free Island Collection: five existing TerrainData heightmaps sampled to independent mesh assets; no source TerrainData editing.
- Modular SciFi Pack and Abandoned Factory (Lite): existing walls/door, motor, control cabinet, barrels/debris.
- Flora-Form: coastal shrubs on islands, material copies with URP cutout support.
- `D:/Downloads/harbor_crane.glb`: user-provided source; duplicate `(1)` file has identical SHA-256. Imported once. Original author/license cannot be established from the local filename alone and is not invented here.
- WaterWorks: local code and documentation inspected; legacy volume code adapter exception documented in WaterCompatibilityNotes. The new ocean/underwater shaders are project-authored additions, not a claim that the original WaterWorks SSR feature was fully ported.
- Project-authored procedural assets: seabed mesh, ruin structural members, island mesh extraction, kelp/seagrass ribbons, sea fans, fish silhouettes, caustic pattern, particle masks, sand/concrete noise texture, soft light-shaft geometry and ocean shaders.
- `Audio/UnderwaterAmbience.wav`: locally synthesized filtered noise and low sine tones, seed 73129, 16 seconds, mono 22.05kHz PCM. No audio extracted from reference media.
- No external assets downloaded or AI-generated raster textures used for this map.
