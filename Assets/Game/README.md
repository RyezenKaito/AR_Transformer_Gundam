# Game

Code dùng chung đang có nằm trong Features/AR và Features/Characters. Core, Scenes, các Features còn lại và Shared dành cho bước phát triển tiếp theo; việc chia thư mục không tạo thêm gameplay.

- Scenes: scene chính của game khi bắt đầu xây dựng.
- Core: khởi động, chuyển scene, lưu tiến trình.
- Features: chức năng game; đặt Scripts, Prefabs, Data, UI theo nhu cầu thực tế.
- Shared: UI, VFX, Audio dùng ở nhiều chức năng.

Toàn bộ nội dung trong Assets/Models giữ nguyên, bao gồm các demo riêng của model. Quy tắc đầy đủ ở Docs/Guides/ProjectStructure.md tại gốc project.
