# HomeLobby horizontal navigation

The Laboratory menu is a permanent horizontal sub-navigation row below the main header.
Items: Lobby, Weaponry, Strike Design, Update. Clicking the main Laboratory button returns to Lobby.
The row is visible in Laboratory (Lobby and Weaponry). It is hidden in Battle,
Inventory and Shop, and returns when Laboratory is selected.
There is no expanding dropdown or full-screen input blocker in horizontal mode.

The left Switch Gundam button and six-axis radar remain visible. The left unit name,
role/level, grade and numeric stat grid are inactive, as requested. The radar still
follows the equipped Gundam and sits below the left Switch Gundam button.
The right unit information card retains its statistics;
its Switch Gundam and Weapons buttons are inactive and the card has been shortened.
